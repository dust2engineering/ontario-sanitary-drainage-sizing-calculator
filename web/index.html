Ontario Building Code Part 7 sizes sanitary drainage by hydraulic load in fixture units: count the fixtures (Table 7.4.9.3), then read the smallest pipe whose table capacity covers the load — branches in Table 7.4.10.6.-B, stacks in 7.4.10.6.-A (with a per-storey cap), and building drains in 7.4.10.6.-C by slope. A building drain or sewer to a public sewer is never smaller than NPS 4.
